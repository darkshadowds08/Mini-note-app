# مصغرة النوتة المالية (Mini Note Finance) 📱💰

تطبيق أندرويد متكامل لإدارة الحسابات المالية الشخصية والتجارية، مبني بأحدث معايير تطوير أندرويد الحديثة باستخدام **Kotlin** و **Jetpack Compose** مع معمارية **MVVM** وقاعدة بيانات **Room**.

---

## ✨ المميزات الرئيسية (Key Features)

- 🇸🇩 **العملة المعتمدة:** الجنيه السوداني (`ج.س`) لكافة العمليات المالية والإيرادات والخصومات والتقارير.
- 🗂️ **واجهات ونوتات متعددة (Workspaces):** إمكانية إنشاء واجهات مالية منفصلة (مثل: النوتة الشخصية، نوتة المتجر، نوتة العمل الحر) والتنقل بينها أو حذفها بكل سهولة.
- ➕ **إدخال المعاملات بمرونة:**
  - تسجيل إيداع مالي أو خصم.
  - خيار تحديد تاريخ وتوقيت مخصص للعملية أو استخدام تاريخ اليوم تلقائياً.
  - إرفاق صورة أو عدة صور للإيصالات والفواتير ومستندات الدفع.
- 📊 **واجهة تقارير شهرية متقدمة:**
  - مراجعة شاملة عند بداية كل شهر مع تنبيه تفاعلي لمراجعة الأداء.
  - حساب إجمالي الإيرادات، الخصومات، والرصيد الصافي المتبقي (فائض أو عجز).
  - مشاركة تقرير نصي منسق بصيغة تناسب واتساب وتليغرام.
- 💾 **النسخ الاحتياطي والتصدير (محلياً وأونلاين):**
  - **تصدير محلي:** كملف نسخة كاملة `JSON` أو كجدول إكسل `CSV` مع ترميز سليم للغة العربية (UTF-8 BOM).
  - **تصدير ومشاركة عبر تليغرام:** إرسال مباشر لتطبيق تليغرام، أو رفع أونلاين مباشر عبر بوت تليغرام (Telegram Bot API) دون الحاجة لتطبيق تليغرام على الجهاز.
- 📥 **استرداد من النسخة المحلية (Backup Restore):**
  - فحص ملفات النسخ الاحتياطية السابقة وإظهار تفاصيلها وعدد الحركات وقيمتها قبل التطبيق.
  - خيار **الدمج والإضافة** (دون حذف البيانات الحالية) أو **الاستبدال الكامل**.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Language:** Kotlin 2.x
- **UI Toolkit:** Jetpack Compose (Material 3)
- **Local Database:** Room Database with Kotlin Coroutines & Flow
- **Architecture:** MVVM (Model-View-ViewModel) + Clean Data Layer
- **Networking:** OkHttp 4 for Telegram Bot API & Online Sync
- **Images:** Coil Compose for receipt attachments
- **Testing:** Robolectric & AndroidX Test suite

## 🚀 كيفية تشغيل وبناء المشروع (How to Build & Run)

### 1. المتطلبات:
- **Android Studio** (Koala / Ladybug أو أحدث)
- **JDK 17** أو أحدث
- جهاز هاتف أو محاكي يعمل بنظام **Android 7.0 (API 24)** أو أحدث

### 2. خطوات الفتح والبناء:
```bash
# استنساخ المستودع (Clone the repository)
git clone https://github.com/YOUR_USERNAME/mini-note-finance.git

# الانتقال إلى مجلد المشروع
cd mini-note-finance
```

1. افتح **Android Studio** واختر **Open** ثم حدد مجلد المشروع.
2. انتظر اكتمال مزامنة Gradle (Sync Project with Gradle Files).
3. اضغط على زر **Run ▶** لتشغيل التطبيق على الهاتف أو المحاكي.

### 3. استخراج ملف التثبيت (Build APK):
من شريط القوائم العلوي في Android Studio:
```
Build > Build Bundle(s) / APK(s) > Build APK(s)
```
ستجد الملف المترجم جاهزاً في المسار:
`app/build/outputs/apk/debug/app-debug.apk`

## 🔒 الخصوصية والأمان (Privacy & Security)
- التطبيق يعمل بالكامل محلياً وبشكل غير متصل (Offline-First) لضمان سرية وخصوصية بياناتك المالية.
- لا يتصل بالإنترنت إلا عندما تطلب صراحةً رفع نسخة احتياطية إلى تليغرام عبر الرمز الخاص بك.
